# 价格比较与 AA 成本视图

「价格」位于「用量」与「综合」之间，使用 OpenRouter 官方模型目录，展示文本输入、输出每百万 token 美元报价，默认按输入价格降序，点击价格表头可切换升序；输入价格相同时按输出价格以相同方向排序。零价格是有效报价；不同上下文阶梯、缓存和路由可能影响实际费用。现有 models.dev 模型详情保持原用途，不再新增 models.dev 价格榜。价格页展示模型及报价，不合并成公司最低价。

AA 综合、编程、图片、视频榜通过成绩表头切换成绩和成本，显示当前选中值。切换分数、成本或速度均保持原榜单顺序及排名变化；成本比例及色条以筛选后同榜最高已知成本为基准，缺失成本不产生价格色条。公司行的成本对应其最强模型。切换与图片导出共用相同投影。

AA 综合使用官方 Intelligence Index 加权平均每任务成本。原榜单采集页不含此字段；服务端通过固定官方模型页获取，在模型名称和成绩完全匹配时合并；来源暂不可用时仅复用同名同成绩的旧成本。AA 编程使用官方平均任务尝试 API 成本。AA 图片来源按 1024×1024 默认设置的每千张报价换算为每张；AA 视频按来源每分钟报价显示，分辨率及设置可能不同。零值有效、缺失显示破折号。四类口径不能混排。

采集器仅访问固定上游地址；OpenRouter 价格入口不需要用户 API Key。共享价格接口提供输入和输出，模型数据源返回报价的原有时间；OpenRouter 结果短期缓存并在失败时返回错误，不把数据缺失当免费。无完整 Xcode、Windows 原生运行环境时分别记录编译及真实运行边界；Mac 原生截图在忽略目录 `work/price-research/`。

2026-10-28 已在新加坡采集函数和深圳主函数上基于各自现有代码进行最小更新，未改函数设置或引入工作区其他改动。新加坡两个固定接口均验证未认证 403、认证成功：OpenRouter 返回 457 条文本报价，AA 综合有 27 条任务成本；深圳价格榜读取成功。通过原有贡献资格刷新后，AA 综合、图片、视频分别返回 28/106/34 条，其中 27/101/32 条有成本。变更前云端代码、校验和、部署与截图证据位于忽略目录 `work/price-research/`。

AA 速度选项：综合榜使用 AA 公布的中位输出速度（token/秒，越大越快）；编程榜使用评测代理平均任务墙钟时间（秒/任务，越小越快）。两者测量口径不同，不能跨榜比较。缺失数据保持原位置并显示横线，公司行沿用最强模型对应的指标；百分比和色条以当前榜可用数值的最大值为基数。图片和视频排名源暂未提供可安全匹配的同口径速度，因此不提供此选项。
