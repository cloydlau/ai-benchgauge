# 基础设施年度预算

| 项目 | 年度预算 |
| --- | ---: |
| 云服务 | ¥600 |
| 对象存储 | ¥100 |
| 运行日志 | ¥100 |
| 合计 | ¥800 |

云服务用于榜单查询、数据同步和日常服务运行；对象存储用于保存榜单快照、模型资料、图标等静态资源；运行日志用于运行监测、问题排查和日常维护。以上为年度预算预留，包含用量波动空间，非实际账单。

金额估算不细于百元，允许千元、万元等更粗粒度。公共计算层默认对正数单项向上取整到百元；按月项目先累计再取整，分组与总额累加已取整单项。零保持零，未核算保持空值；工程计数不取整。

预算定义维护在 `apps/weapp/src/core/investment.js`；小程序直接读取，iPhone/iPad 在构建时生成相同内容。桌面及榜单图片导出没有此成本区。
