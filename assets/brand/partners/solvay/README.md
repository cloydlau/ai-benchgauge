# Solvay Institutes avatar

`logo.png` is the official International Solvay Institutes favicon/avatar,
downloaded unchanged on 2026-10-27 from:

https://solvayinstitutes.be/wp-content/uploads/2025/07/logo-IIPC-sans-fond-verticall-carre.png

The institute's official conference photograph gallery uses this mark:
https://solvayinstitutes.be/home/conferences/pictures/

SHA-256: `f3b7f2fcbb383f0677c1f13e01f7ac8c3c828df1645cb3e1c538cd49d9bfe78a`.
It identifies the institution associated with the 1927 conference; it is not
a portrait of photographer Benjamin Couprie. Ownership remains with the
International Solvay Institutes; no repository MIT license is asserted.

`Scripts/source-logos.mjs` exports proportion-preserving 54×54 PNGs in the
original colors for both mobile clients and themes. The About photo credit
places this avatar before the photographer's name in one shared link to the
original photograph record. The mark is bundled for offline use.
