# GitHub icon

`logo.svg` is GitHub's official Octicons `mark-github-24`, pinned to revision
`9a274e212ee25c400ff666ce25a57866b7eacc25`. `source.json` records its URL,
SHA-256 and the MIT license hash; `OCTICONS-LICENSE.txt` is the upstream license.
`LICENSE.txt` retains the separate Tabler license for the WeChat platform mark.

`node Scripts/source-logos.mjs` renders the SVG to the shared transparent
`assets/logos/github.png`; `--check` verifies the source and export. Desktop
repository links and mobile GitHub Actions contributor avatars share it.
The Octicons MIT notice is packaged with each client. GitHub is a trademark
of its owner; inclusion identifies the repository and does not imply endorsement.
