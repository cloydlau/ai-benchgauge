# Source brand marks

These are official vendor marks used to identify the six leaderboard sources
in About and every category's source tabs. `sources.json` records the official page, exact download URL, retrieval
date, original/download hashes, conversions and consumers. No icon was redrawn
or generated by AI. These marks retain their owners' rights; the repository's
MIT license and leaderboard data licenses do not cover them. See `NOTICE.txt`.

Each vendor's canonical artwork is `logo.svg` or `logo.png` in its own folder.
Vercel and OpenRouter provide separate official `logo-dark.svg` variants. Arena's
official SVG includes a dark-mode media rule; the exporter selects that rule
for the dark PNG. Tencent and Artificial Analysis PNGs are lossless exports
of their official ICO frames. Epoch uses its official teal SVG favicon.

Generate the 84×84 transparent, proportion-preserving runtime PNGs with:

```sh
node Scripts/source-logos.mjs
node Scripts/source-logos.mjs --check
```

`apps/ios/UI/Resources/SourceLogos` contains generated Apple bundle copies,
loaded in their original colors. The mini-program Vite build invokes the same
renderer and packages the same files under `assets/source-logos/`, including
`NOTICE.txt`. Runtime pages never fetch logos from a third-party server.
Update the manifest when intentionally replacing upstream artwork; do not edit
the runtime exports as new source images. Keep native `scaledToFit` and WeChat
`aspectFit` so rectangular marks preserve their proportions.
Source tabs use the same theme-specific exports on a small neutral surface so
the original marks remain visible over selected brand colors. All board kinds
resolve their source identity through the shared `SourceTabThemes.json` catalog.

The `wechat/` subdirectory separately holds the Tabler WeChat outline used in
the About platform list. It is not a leaderboard source or official vendor
artwork. The same exporter generates its 54×54 neutral theme variants for both
mobile clients; see `wechat/README.md` for provenance and the bundled MIT notice.

`weibo/` contains the Simple Icons Sina Weibo mark (CC0 1.0) for the artwork
attribution's original-post link. Both mobile clients use the same neutral PNG
exports; see `weibo/README.md` for source and licensing details.

`solvay/` holds the official International Solvay Institutes avatar used beside
the About artwork's historic-photo credit. The same exporter preserves its
original colors in both themes; see `solvay/README.md` for provenance.
