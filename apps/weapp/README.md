# AI 天梯 · 微信小程序

与 Watrek 使用同类技术栈：Vue Mini 1.2.16、Vant Weapp 1.11.7、weapp-vite 7.5.0、Tailwind CSS 4 / PostCSS。WXML 使用原生小程序组件，CSS 编译为 WXSS。客户端不依赖 Swift 或桌面账号。

榜单页、关于页和导出截图共用 iOS 标题字形：中文「天梯」为演示夏行楷，英文为 Snell Roundhand Bold。字形以离线 SVG 和 Canvas 路径随包提供，保留可访问标题，字体许可收录在关于页。修改原生标题字体后，在 macOS 运行 `swift Scripts/weapp-brand-glyphs.swift` 更新字形资源。

## 开发

在仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm test:weapp
pnpm build:weapp
pnpm open:weapp
```

持续开发使用 `pnpm dev:weapp`，同时监听并自动上传小程序。根目录 `./dev.sh` 也接入同一个上传监听，两种启动方式不会重复上传。微信开发者工具导入 **apps/weapp**，`miniprogramRoot` 指向 `dist/`。构建自动复制已有品牌、供应商图标和许可证，不维护第二份位图源码。主包约 390 KB。

当前 `project.config.json` 使用 BenchGauge 正式 AppID `wx80689a4ae64a0c33`，本机私有配置已移除临时测试号的 AppID 覆盖。只读公开榜单不需要 AppSecret。

全端公开版本共用 `config/app.json` 的北京时间日期号 `YYYYMMDD`（例如 `20261028`），小程序关于页和上传版本与原生客户端一致。发布前在仓库根目录运行 `./Scripts/bump-version.sh`，默认取当天北京时间，也可传入显式日期；同一天保持相同版本。构建和上传冻结该共用版本，跨零点不会变化。`MP_VERSION` 只允许与共用配置相同的日期值，不能单独覆盖某一端。

在小程序后台添加 request 合法域名 `https://ai-benchgauge-qrwtdokchx.cn-shenzhen.fcapp.run`。FC 函数统一命名为 `ai-benchgauge`，构建时从 Swift 共用配置读取其新地址。项目保留 `urlCheck: true`；本机开发时可在被忽略的 `project.private.config.json` 中本地关闭域名校验，该设置不替代线上域名配置。参考[微信网络说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)。

## 功能

- 底部悬浮玻璃 TabBar 支持点击或栏内拖动切换综合、编程、图片、视频；拖动先预览选中位置，松手后才加载最终分类，适配安全区和明暗外观；共八份完整榜单；点击或拖动随内容滚动的「任务测评／用户盲测」，也可在榜单内横向滑动切换，表头左侧显示实际榜单名称与不含年份的来源日期，标题、日期和主题色搜索图标依次居左并垂直居中，窄屏下日期和搜索可一起落在标题下方；月日统一用斜线，发布与刷新时间同用中性色；来源说明独占上一行。
- 模型／公司切换：公司取筛选后最强模型分数，不使用平均分或型号数量加分。厂商和模型家族图片分别保留。
- 模型和公司表头的搜索图标向两侧渐变展开为整行搜索框，原表头淡出，展开完成后再聚焦。在本地匹配当前榜单的模型名或公司名（忽略大小写，支持多个词），与国家和源码筛选取交集；公司名在公司聚合完成后筛选，保留原排名、相对原榜首的比例和旗下模型。模型榜与公司榜各自保留关键词，关键词跨来源、分类保留；失焦时非空搜索保留输入框，空搜索收起，吸顶时去掉圆角。清空保留搜索框，取消清空当前榜单关键词并收起；全局清除筛选会清空两类关键词。关键词仅保存在当前页面，不写入偏好或分享链接。
- 公司行提供「套餐／按量」按钮，只展示已收录的官方入口。简中优先大陆站，繁中和英文优先国际站；MiniMax 编程订阅与海螺创作套餐、字节编程与即梦／Dreamina 按分类区分。小程序不能直接唤起系统浏览器访问任意网址，点击即复制，仅提示「已复制」；复制失败可重试。
- 所有分类、任务测评与用户盲测共用一组国家、开源／闭源／未知筛选，切换分类或榜单都沿用已选值，清除筛选全局生效；未核实资料保持未知。
- 简中、繁中、English；系统／浅色／深色；保存语言、分类、分组和筛选偏好。
- 右上角菜单转发携带分类、模型／公司、任务测评／用户盲测、语言、外观及全局共享的国家和源码筛选。接收时分享参数优先于本机偏好，并保存还原后的设置；未筛选的分享也会清除接收端原有筛选。
- 主标题、模型／公司切换与微信胶囊同排；切换控件高度跟随胶囊实测高度。副标题放在主标题右侧，复用简介后半句，以两行显示：「双榜对照，选得明白；」「余量追踪，用得有数。」；三种语言均固定为两行；副标题以 11px 为基准，上下各向主标题内侧收进约 1.5px（随字号同比例缩放），按实测文字宽度适配，主副标题按二者合计宽度共用缩放比例，始终留在同一行内。问号使用副标题原字号，相对第二排文字绝对定位，贴近「用得有数。」末尾，收掉中文句号右侧空白，不参与文字排版和宽度计算；与第二排文字垂直居中，模型／公司切换左右布局间隔均为 8px，切换及微信胶囊保持原尺寸。PC 端同样在主标题右侧显示两行。
- 时间单行显示：只提供一个则显示该时间，两者都有则显示较新的一个。下拉或点击时间重新读取快照，失败保留已保存数据和原时间。自动刷新不显示失败提示，也不触发下拉刷新动画。
- 手动下拉刷新仅在发起手势的榜单展示原生回弹区域；松手后在魔方可见区域持续显示三个动态圆点，避开顶部裁切。已有请求会共用并等待完成，快速响应也保留短暂可见反馈；结束时圆点随回弹淡出，失败保留原榜单。浅色、深色及减少动态效果均有对应样式。
- 公司分数明细、完整模型名与复制、回到顶部、榜单截图、来源链接复制和第三方开源声明（中性编号展示，可展开阅读完整版权及许可文本，页面不列技术栈名称）。点击国旗提示国家名称，点击锁图标提示开源／闭源／未知，文字跟随界面语言；滑动切换榜单不会误触提示。语言和外观各用一个按钮；移动界面不展示应用作者与应用协议。
- 截图仅导出当前分类的两个完整榜单，合为一张并排长图，保留当前筛选、完整名称和原始排名；预览与保存均只有这一张图片。长图按固定大小的 Canvas 条带绘制并写入同一个 PNG，避免超长 Canvas 和分页轮播；关闭预览会清理临时图片。
- 底部相机按钮导出当前分类的双榜对照，沿用模型／公司分组、各榜筛选、语言和外观。输出保留完整名称及全部条目，长榜单按画布尺寸分页；可逐页预览大图或全部保存到相册，保存失败后重试会从未保存的一页继续。生成图片仅使用榜单 PNG 和本地素材，临时素材随后清理。
- 长榜单使用与玩水信息流相同的窗口策略：保留完整数据和总高度，只渲染视口附近的行；前后缓冲、边界阈值和重叠行复用减少滚动时的数据桥更新。

使用原生 `scroll-view` 与立体魔方翻转，左右滑动或点来源切换，并对齐浏览名次。转场先等待目标榜单的原生滚动位置稳定，超出短榜单范围时按实际视口限制，随后旋转并平滑调整顶部可见区域；快速连续点选衔接执行，取消或离开页面会清理待执行转场，遵循系统减少动态效果设置。首次进入有轻微登场动画。不嵌入网页。账号额度仍在 PC 端提供，小程序不读取或上传账号密钥。

## 共享数据

关于页的「成本与投入」参考 Watrek，展示工程统计、适用项目的年度预算及累计研发投入：云服务 ¥1,200/年、对象存储 ¥400/年、运行日志 ¥600/年、小程序认证预留 ¥300/年。词元沿用 Watrek 的算法，自 BenchGauge 首次提交（2026-09-21 17:09:38 +08:00）起，将开发时长按平均月长（365.2425 天 ÷ 12）折算并四舍五入，乘以 ¥2,000/月累计；不会固定乘以 12。估算合计为年度预算 ¥2,500 加词元累计投入，不标为年度总成本。金额参考 Watrek 同类项目的约千名用户预算，明确标注为估算而非实际账单；人力、数据维护、运营暂未核算，不计入合计。地图、手机号验证、短信、验证码、OCR、独立数据库、独立域名及证书等无关项不展示。不将工程统计折算成金额。提交次数取本仓库完整 Git 历史；代码行数统计 `Sources/`、`apps/`、`fc/` 下已跟踪的 UTF-8 文本，不含依赖、构建目录、`generated/`、锁文件、符号链接及二进制。每次构建自动统计，不维护手填数字。CI 必须完整检出历史；隔离上传构建通过 `BENCHGAUGE_INVESTMENT_ROOT` 从原仓库读取统计，不会误统计临时目录。

分享使用带版本的紧凑状态参数，不携带榜单数据或账号信息，榜单仍读取共享快照。旧的分类／来源链接继续可用。选择「跟随系统」时，接收端首次显示分享时的明暗效果并保留该选项；接收者主动选择外观或之后改变系统外观时，恢复本机外观逻辑。关于页转发也保留完整上下文，冷启动返回榜单时还原原来的分类和设置。

构建读取 `Sources/LeaderboardKit/SharedLeaderboardConfiguration.swift` 的共享 HTTPS 地址，与 Apple / Windows 使用同一服务。可用环境变量覆盖：

```sh
VITE_BENCHGAUGE_SHARED_ENDPOINT=https://your-shared-service.example pnpm build:weapp
```

只调用 `GET /v1/boards/{kind}`，不获取贡献资格、访问原站或上传 HTML。共享池由现有具备原站访问能力的客户端更新。读取缓存不改写 `fetchedAt`；旧抓取时间、倒退或丢失的已有源时间不能覆盖更新的本地快照。

PNG 随快照显示，不额外访问源站图片域名。缓存失败不影响有效网络结果，关闭页面取消它发出的请求，两张榜单独立完成和呈现。

本机自动上传读取 `calmmit.config.json` 声明的上传凭证，默认位置为 `apps/weapp/private.wx80689a4ae64a0c33.key`；私钥、回执和日志均被 Git 忽略。可通过 `MP_PRIVATE_KEY_PATH` 显式指定其他本机路径。新增或轮换密钥会被自动检测，启动时也会补传尚未上传的源码。`WEAPP_AUTOPUBLISH=0` 关闭自动上传；手动立即上传使用 `pnpm upload:weapp`，只启动上传监听使用 `pnpm watch:weapp`。
