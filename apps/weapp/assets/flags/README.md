# Export country flags

64×48 PNGs rasterized from the 4:3 SVGs in [flag-icons 7.6.0](https://github.com/lipis/flag-icons/tree/v7.6.0), using @resvg/resvg-js 2.6.2. Original MIT license is preserved in LICENSE.

Two-letter source codes are included except HK, MO and TW, which resolve to CN through the shared country policy. Unknown or unavailable country images fall back to a readable country code or question mark. Assets are bundled; export never requests a remote flag.
